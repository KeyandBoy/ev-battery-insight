# 数据目录说明

- `raw/`：公开数据原文件，只读保存，不提交到 Git，需记录来源和许可协议。
- `processed/`：经过 EV DataForge 清洗、映射和单位统一后的数据。
- `simulated/`：程序生成的模拟数据，用于开发和回归测试。

## 标准单位

温度使用摄氏度，电压使用伏特，电流使用安培，功率使用千瓦，里程使用千米，容量使用千瓦时，荷电状态使用 0 至 100 的百分比。

## 标准关联键

- `vehicle_id`：车辆唯一标识。
- `timestamp`：ISO 8601 时间。
- `station_id`：充电站唯一标识。
- `model`：车型名称。

不同来源没有共同车辆 ID 时，不得直接声称数据属于同一车辆。应在数据说明中标记为模拟关联或分层验证数据。
