# Unified Visualization Platform 开发路线

## 第一阶段：可运行闭环

- 生成模拟车辆、电池、充电和故障数据。
- 使用 EV DataForge 清洗并导出标准数据。
- 完成电池健康评分。
- 完成风险车辆列表。

## 第二阶段：多视图分析

- 接入 Region 的降维和聚类能力。
- 接入 DataFlow 的层次分析和综合大屏。
- 接入 Voronoi 的车型和电池层次展示。
- 接入 Chain-Connect 的车型、供应商和故障关系图。
- 完成全局筛选和跨图联动。

## 第三阶段：智能化与验证

- 增加算法自动推荐和聚类稳定性分析。
- 增加风险原因解释和自动报告。
- 接入公开电池或充电数据。
- 对模拟数据、公开数据和不同算法进行对比实验。

## 第一版验收标准

上传一份车辆电池 CSV 后，系统能够完成字段识别、数据质量检查、健康评分、车辆分群、高风险车辆展示和结果导出。
